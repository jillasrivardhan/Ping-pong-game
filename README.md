# 🏓 Ping Pong Game

A modern browser-based **Ping Pong (Pong) Game** built using **HTML, CSS, and JavaScript**. This project recreates the classic arcade game with smooth gameplay, AI opponent, score tracking, and a clean responsive interface.

## 📌 Features

- 🎮 Single-player gameplay against an AI opponent
- 🖱️ Mouse and ⌨️ Keyboard controls
- 🤖 Intelligent computer-controlled paddle
- ⚡ Smooth ball movement and collision detection
- 📊 Live score tracking
- 🏆 Game-over screen with restart option
- 🎨 Modern UI with animations and visual effects
- 🌐 Runs directly in any modern web browser


## 🎮 Controls

| Action | Control |
|---------|---------|
| Move Paddle | Mouse |
| Move Up | ↑ Arrow Key |
| Move Down | ↓ Arrow Key |
| Restart Game | Restart button after Game Over |

---

## 🎯 Gameplay

- Control the left paddle.
- The AI controls the right paddle.
- Prevent the ball from passing your paddle.
- Score points when the opponent misses the ball.
- The first player to reach the winning score wins the game.
